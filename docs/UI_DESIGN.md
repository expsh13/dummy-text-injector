## 4. ハイライト表示

### 4.1 スタイル一覧

| 状態 | CSSクラス | 枠スタイル | 背景 |
|------|----------|-----------|------|
| ホバーのみ | `__dti-hover` | `2px solid #6366f1` | なし |
| 選択中のみ | `__dti-selected` | `2px solid #f59e0b` | なし |
| 変更済みのみ | `__dti-modified` | `2px dashed #10b981` | なし |

### 4.2 複合状態

複数のクラスが同時に付与された場合の表示。CSSの記述順で優先度を制御する。

| 状態の組み合わせ | 適用されるクラス | 枠 | 背景 |
|----------------|---------------|---|------|
| ホバー + 選択中 | `__dti-hover __dti-selected` | 橙実線（`__dti-selected` が勝つ） | なし |
| ホバー + 変更済み | `__dti-hover __dti-modified` | 青実線（`__dti-hover` が勝つ） | 薄緑 `#10b98120` |
| 選択中 + 変更済み | `__dti-selected __dti-modified` | 橙実線（`__dti-selected` が勝つ） | 薄緑 `#10b98120` |
| ホバー + 選択中 + 変更済み | 3クラス全て | 橙実線（`__dti-selected` が勝つ） | 薄緑 `#10b98120` |

### 4.3 CSS実装

```css
/* 変更済み（最低優先度） */
.__dti-modified {
  outline: 2px dashed #10b981 !important;
  outline-offset: 1px !important;
}

/* ホバー（中優先度） */
.__dti-hover {
  outline: 2px solid #6366f1 !important;
  outline-offset: 1px !important;
  cursor: crosshair !important;
}

/* 選択中（最高優先度） */
.__dti-selected {
  outline: 2px solid #f59e0b !important;
  outline-offset: 1px !important;
}

/* 変更済み要素にホバーまたは選択が重なった場合 → 薄緑背景 */
.__dti-modified.__dti-hover,
.__dti-modified.__dti-selected {
  background-color: #10b98120 !important;
}
```

**設計ポイント:**
- `outline` プロパティを使用し、要素のレイアウト（`box-sizing`）に影響を与えない
- `outline-offset: 1px` で要素の境界線と重ならないようにする
- 全スタイルに `!important` を付与し、ホストページのCSSに負けないようにする
- CSSの後方記述が優先されるカスケードルールを利用して優先度を制御

## 5. インタラクション設計

### 5.1 カーソル変化

| 状態 | カーソル |
|------|---------|
| 通常（選択モードOFF） | ページのデフォルト |
| 選択モードON・テキスト要素外 | ページのデフォルト |
| テキスト要素上ホバー | `crosshair` |
| パネルヘッダー上 | `move` |
| パネルボタン上 | `pointer` |

### 5.2 キーボード操作

| キー | 条件 | アクション |
|------|------|-----------|
| `Escape` | 要素が選択中 | 選択をクリア（モード維持） |
| `Escape` | 選択なし | 選択モードをOFF |
| `Cmd/Ctrl` + クリック | テキスト要素上 | 複数選択のトグル |

### 5.3 マウス操作

| 操作 | 対象 | アクション |
|------|------|-----------|
| ホバー | テキスト要素 | 青枠ハイライト表示 |
| クリック | テキスト要素 | 要素を選択（橙枠ハイライト） |
| Cmd/Ctrl + クリック | テキスト要素 | 複数選択に追加/除外 |
| クリック | 非テキスト要素 | 無反応 |
| ドラッグ | パネルヘッダー | パネル位置移動 |

### 5.4 アニメーション

| アニメーション | プロパティ | 詳細 |
|-------------|-----------|------|
| ステータスメッセージ消去 | `opacity` | 2.2秒後にフェードアウト、`transition: opacity 0.3s` |
| フッターの緑ドット | `opacity` | `animation: blink 1.8s infinite`（1 → 0.3 → 1） |
| ボタンホバー | `opacity` | `transition: opacity 0.15s`、ホバー時 0.82、アクティブ時 0.65 |
| 閉じるボタンホバー | `background` | `transition: background 0.15s`、rgba(255,255,255,0.2) → 0.4 |
| 入力欄フォーカス | `border-color` | `transition: border-color 0.15s`、#383854 → #6366f1 |
